# Rozkłady jazdy — Środa Wielkopolska (dane)

Repozytorium zawiera **wyłącznie dane** w formacie JSON, generowane
automatycznie ze strony `autobusy.sroda.wlkp.pl`. Nie edytuj go ręcznie —
każdy przebieg scrapera nadpisuje zawartość.

Pliki są serwowane aplikacji mobilnej przez `raw.githubusercontent.com`.
Zacznij od `index.json`, który zawiera listę linii i nazwy pozostałych plików.
